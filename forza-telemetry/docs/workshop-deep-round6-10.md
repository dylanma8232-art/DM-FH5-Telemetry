# 车辆工坊深度优化 Round 6-10

## Round 6: 调校与比赛关联

### 功能概述
- 在每个调校卡片上显示该调校在实际比赛中的使用统计数据
- 建立调校(tune)与比赛记录(session)的关联关系

### 数据加载
- 新增 `tuneSessionStats` 状态：存储每个调校ID对应的比赛统计
- 新增 `loadTuneSessionStats()` 函数：
  - 从 `/api/sessions` 获取所有比赛记录
  - 按 `session.tuneId` 分组统计
  - 计算每个调校的：比赛次数、最佳圈速、总圈数、关联session列表
- 在 `useEffect` 初始化时加载统计数据

### 卡片显示
- 在车辆信息区域下方新增**比赛统计**面板（3列grid布局）：
  - **比赛次数**：蓝色，使用该调校的比赛数量
  - **最佳圈速**：金色，使用该调校跑出的最快单圈（formatTime格式化）
  - **总圈数**：绿色，累计完成的圈数
- 跨3列显示**查看比赛记录**按钮（仅当有关联数据时显示）
  - 蓝色主题，点击跳转到比赛记录页面
  - 显示关联比赛数量

### 跳转功能
- `onNavigate('sessions', { trackName })` 导航到比赛记录页面
- 传递第一条关联session的赛道名称作为筛选条件

## Round 7: 配件推荐引擎

### 功能概述
- 在调校编辑弹窗中，基于车辆类型和赛道特性自动推荐配件组合
- 位于调校笔记输入框和PI锁定区域之间

### 推荐逻辑
基于两个维度生成推荐：

#### 驱动类型推荐
| 驱动类型 | 推荐配件 | 说明 |
|----------|----------|------|
| FWD（前驱） | 防倾杆、胎压 | 较硬前弹簧+高前防倾杆减少转向不足；略高前胎压(32-34PSI) |
| RWD（后驱） | 差速器、弹簧 | 低差速器减速设定(15-30%)增强弯中稳定性；后弹簧略软提升后轮抓地 |
| AWD（全驱） | 差速器 | 中等差速器设定(40-60%)平衡加速和弯道表现 |

#### 车辆等级推荐
| 等级 | 推荐配件 | 说明 |
|------|----------|------|
| S1/S2 (class>=5) | 空力、刹车 | 加大下压力优先增加后部；升级刹车至赛用级别 |
| 低等级 (class<=2) | 引擎、进气 | 优先升级引擎和进气提升基础马力 |

#### 通用推荐
- 大多数赛道推荐中等偏硬弹簧设定(6-14)，兼顾弯道支撑和路面颠簸吸收

### UI设计
- 紫色标题"配件推荐"，副标题"基于车辆类型和赛道特性"
- 推荐条目使用卡片式布局：
  - 左侧：分类标签（颜色编码：蓝色/绿色/金色/紫色）
  - 右侧：推荐理由文本
  - 背景使用对应颜色的极低透明度填充

## Round 9: 调校工坊交互优化

### 参数分组折叠
- 新增 `collapsedSections` 状态（Set数据结构）
- 新增 `toggleSection(sectionId)` 函数：点击分组标题切换折叠状态
- 四个参数分组支持折叠：
  - `tires`：轮胎参数
  - `suspension`：悬挂参数
  - `drivetrain`：传动系统
  - `aero`：空气动力学
- 分组标题增加：
  - 点击手型光标 (`cursor: pointer`)
  - 折叠指示器（▶ / ▼）
  - `userSelect: none` 防止误选
- 折叠时隐藏参数grid，展开时正常显示
- 传动系统分组使用 `<>...</>` Fragment包裹两个grid（差速器grid + 齿比grid）

### 快捷键支持
- 新增 `useEffect` 监听全局键盘事件
- 仅在弹窗打开(`showModal`)且焦点不在输入框中时生效
- 支持的快捷键：
  | 快捷键 | 功能 |
  |--------|------|
  | `Esc` | 关闭编辑弹窗 |
  | `Ctrl+S` / `Cmd+S` | 保存调校 |
| `Ctrl+D` / `Cmd+D` | 复制调校（预留） |
- 快捷键提示显示在保存按钮下方
- 使用 monospace 字体 + 背景色底框的样式
