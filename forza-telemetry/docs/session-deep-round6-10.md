# 比赛中心深度优化 Round 6-10

## Round 6: 数据导出增强

### 增强版CSV导出
- 新增 `exportEnhancedCSV()` 函数，导出包含以下字段的增强版CSV：
  - 基础字段：时间戳、速度、档位、转速、油门、刹车、转向、位置
  - **轮胎温度**：前左/前右/后左/后右四轮温度
  - **悬挂行程**：四轮悬挂压缩量
  - **G力数据**：横向G力、纵向G力、垂直G力
  - **状态标记**：是否漂移、ABS激活、牵引力控制激活
  - **原始加速度**：三轴加速度数据
- 使用 BOM 标记确保中文兼容
- 下载完成后 toast 提示导出行数

### PDF报告导出
- 新增 `exportPDFReport()` 函数，使用浏览器 print 功能生成 PDF
- 打开新窗口，渲染完整的分析报告页面：
  - **报告头部**：赛道名称、日期、圈数
  - **综合评分区域**：总分大字显示、等级标签（颜色编码）
  - **五维评分**：柱状进度条展示各维度得分
  - **最需改进列表**：优先级标签（最需改进/次要改进/建议关注）
  - **成绩统计**：最快圈速、最高速度、平均速度
  - **制动 & 加速效率**：效率指标颜色编码
  - **打印按钮**：点击即可保存为 PDF
- 优化 `@media print` 样式，确保打印效果美观
- 页脚显示生成时间

### UI变更
- Session卡片操作栏新增两个按钮：
  - **增强CSV**：蓝色主题按钮，触发增强版CSV导出
  - **PDF报告**：紫色主题按钮，触发PDF报告生成

## Round 7: 比赛对比功能

### 核心功能
- 新增对比状态管理：
  - `compareSessionA` / `compareSessionB`：存储对比的两个session ID
  - `compareAnalysisA` / `compareAnalysisB`：存储对比分析数据
  - `compareLoading`：加载状态

### 对比流程
1. 点击 Session 卡片上的**对比**按钮选择第一个Session（标记为A）
2. 再点击另一个Session选择第二个（标记为B）
3. 系统自动并行加载两个Session的分析数据
4. 在对比面板中展示并排对比结果

### 对比维度（8项）
| 维度 | 单位 | 说明 |
|------|------|------|
| 最快圈速 | s | 越小越好（反转比较方向） |
| 最高速度 | km/h | 越大越好 |
| 平均速度 | km/h | 越大越好 |
| 制动效率 | % | 越大越好 |
| 油门控制 | % | 越大越好 |
| 走线评分 | % | 越大越好 |
| 牵引力利用率 | % | 越大越好 |
| 综合评分 | 分 | 越大越好 |

### 差异高亮
- `getCompareDiff()` 函数计算差异值：
  - 正向指标（速度等）：正值绿色（A更好），负值红色（B更好）
  - 反向指标（圈速）：正值红色（A更慢），负值绿色（A更快）
  - 差异超过阈值的行添加背景高亮

### UI组件
- 对比面板头部：A/B 选择槽位，VS 分隔符
- 对比表格：4列布局（维度、A值、B值、差异）
- Session卡片上的**对比**按钮：选中时显示"A已选"/"B已选"状态，金色高亮
- **清除选择**和**开始对比**操作按钮

## Round 8: 分析算法优化

### 走线分析增强
- 在走线分析面板底部新增**走线改进建议**区域
- 触发条件：
  - 偏差比例 > 15%：提示贴近理想走线
  - 严重偏离 > 5%：提示注意刹车点选择
  - 评分 < 60%：建议回顾回放练习弯道
- 使用金色半透明背景框，醒目但不刺眼

### 制动分析增强
- 在制动分析面板顶部新增**制动模式检测**区域
- 晚刹车检测：
  - 条件：起始速度 > 200km/h 且速度损失 > 100km/h 的事件超过2次
  - 提示：可能存在刹车点过晚的问题
- 早刹车检测：
  - 条件：起始速度 < 100km/h 且速度损失 < 30km/h 的事件超过3次
  - 提示：可能存在刹车过早的问题
- 使用红色半透明背景框

### 加速分析增强
- 在加速分析面板顶部新增**出弯加速效率**区域
- 低效加速检测：
  - 条件：加速率 < 40km/h/s 的事件超过3次
  - 提示：出弯给油不足或档位选择不当
  - 建议：提前降档至合适弯中档位
- 使用金色半透明背景框
- JSX特殊字符转义：`<` 和 `>` 使用 `&lt;` 和 `&gt;`

## Round 9: UI打磨

### Session列表分页
- 新增分页状态：
  - `sessionPage`：当前页码（默认1）
  - `SESSION_PAGE_SIZE = 20`：每页显示条目数
- `paginatedSessions`：useMemo 计算当前页数据
- `totalPages`：自动计算总页数
- 分页控件：
  - 首页 `<<` / 上一页 `<` / 下一页 `>` / 末页 `>>`
  - 页码显示："1 / 5 页"
  - 首页/末页按钮在边界时禁用（透明度降低）
  - 控件位于列表底部，居中对齐

### 右侧分析区域布局
- 对比面板增加选择槽位视觉指示（蓝色/金色半透明背景）
- 对比表格行差异背景高亮（极低透明度颜色）
- 各分析面板间距和padding统一优化

### 颜色方案统一
- 严重程度颜色规范：
  - `var(--danger)` / `#f85149` / `#dc2626`：严重/错误/需要紧急改进
  - `var(--warning)` / `#d29922`：警告/需要关注
  - `var(--success)` / `#3fb950` / `#22c55e`：良好/优秀
  - `#58a6ff`：信息/次要操作
  - `#bc8cff`：特殊功能（PDF导出）
- 按钮颜色根据功能统一：
  - 导出类：蓝色系
  - 增强功能：蓝色/紫色
  - 删除：红色
  - 对比：金色
