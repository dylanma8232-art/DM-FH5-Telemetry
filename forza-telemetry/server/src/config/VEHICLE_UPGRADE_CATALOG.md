# 车辆改装资料库

`vehicle-upgrades.json` 保存车辆专属资料，`upgrade-catalog.js` 保存 FH5 的通用改装结构与解锁规则。没有车辆档案时，客户端不得显示猜测配件；有档案时，将该车的引擎、进气、传动置换和空气动力学等专属选项，与发动机、平台操控、传动、轮胎轮毂等通用大项合并。

模型按四层解析：

1. 通用槽位定义：赛车刹车、悬挂、防倾杆、变速箱、差速器等名称和联动规则只维护一份。
2. 车辆类型模板：目前区分燃油公路车和电动公路车，电动车不会继承燃油发动机配件。
3. 车辆能力覆盖：`commonSlotOverrides` 只记录该车的存在、缺失、允许选项子集等差异。
4. 车辆专属槽位：引擎置换、进气置换、宽体、前部空气动力学、后部空气动力学和升级预设逐车保存。

通用表示复用结构，不表示每辆车必然拥有全部选项，也不表示同名配件可以共用精确 PI。`availability` 使用 `source_explicit`、`inferred_common`、`verified_absent`、`unknown` 区分证据状态。

手动与 AI 使用不同策略：

- 手动模式显示完整通用候选枚举和车辆专属资料，`通用候选` 表示需要用户在游戏菜单中核对。
- AI 只选择 `aiEligible: true` 且 PI 至少有保守上界的配件。车辆专属置换、模糊外观、电驱候选和 PI 未知项默认不允许 AI 使用。
- 通用估算为每项提供 `piUpperEstimate`；AI 使用上界累计，并在目标等级下额外保留至少 10 PI、目标值 2% 的安全余量。
- 手动选择 PI 未知配件时允许保存，但最终 PI 状态记为未知；客户端提交的基础 PI 和总 PI 不作为服务端真值。
- 工坊的基础 PI 永远读取车辆档案中的官方原厂 PI。遥测识别到的车辆 PI 只表示玩家当前正在驾驶的实际状态，可能已经改装，禁止作为新方案的起点。每套方案的 PI 单独按“官方原厂 PI + 该方案配件”计算并保存。
- 能用功能状态表达的通用件不维护具体品牌名称：空气动力学使用“原厂、固定、可调”，刹车、悬挂、防倾杆、变速箱和差速器直接标明是否可调。引擎置换、进气置换、宽体和升级预设等真正依赖车辆的内容仍使用车辆专属数据。
- AI 生成后必须先进入配件确认步骤，用户可以逐项修改。最终调教项目和挡位数量只根据用户确认后的配件重新解析，例如可调尾翼解锁后下压力，竞赛七速只解锁一至七挡。
- 引擎置换优先显示正式名称、排量、布局和进气形式，马力只作为辅助信息。车辆表只有功率而没有名称时，会与引擎目录按原厂功率关联；唯一匹配直接显示正式名称，多候选同时显示并标记待核验，未匹配项显示名称待核验，禁止把“750 马力引擎”冒充正式名称。
- 弹簧、车高、逐挡齿比和下压力等车辆敏感范围标为 `vehicle_specific_unknown`。手动模式允许对照游戏填写，AI 保持空白。
- 泥地、越野和漂移方案必须具备该车辆已确认的对应轮胎、悬挂和差速器核心选项；缺少高置信资料时界面会禁用生成，而不是使用公路配件拼出错误方案。驱动形式由用户声明，可自由选择前驱、后驱或四驱；它用于决定差速器配置和调教参数，不会被系统当作一个未经确认的驱动置换配件。

每个键是 FH5 的车辆 ordinal。`slots` 是游戏内可见的大项；`options` 是大项下的实际改装件。`when` 用于描述前序选择条件，支持 `all`、`any`、`not`，以及 `slot + optionIn` / `optionNotIn`。

```json
{
  "profiles": {
    "123": {
      "status": "verified",
      "gameVersion": "2026-07-16",
      "source": [{ "type": "公开资料", "url": "https://example.invalid", "verifiedAt": "2026-07-16" }],
      "slots": [
        {
          "id": "engine_swap",
          "label": "引擎置换",
          "tierSystem": false,
          "options": [
            { "id": "stock", "label": "原厂发动机", "piEstimate": 0 },
            { "id": "v8_62", "label": "6.2 升 V8 发动机", "piEstimate": 42, "performanceScore": 75 }
          ]
        },
        {
          "id": "engine_turbo",
          "label": "增压器",
          "tierSystem": false,
          "options": [
            {
              "id": "race_turbo",
              "label": "竞赛涡轮增压器",
              "when": { "slot": "engine_swap", "optionIn": ["v8_62"] }
            }
          ]
        }
      ],
      "tuneParameters": [
        {
          "id": "downforce_rear",
          "when": { "slot": "aero_rear", "optionIn": ["forza_adjustable"] },
          "range": { "min": 120, "max": 260, "step": 1 }
        }
      ]
    }
  }
}
```

`piEstimate` 是该选项相对该车原厂状态的估算 PI 变化；一键生成会在目标 PI 下保留安全余量。PI 不能再使用全局固定增量。取得游戏内实测结果后，将档案 `piStatus` 设为 `verified`，并加入构建 PI 记录，即可用于“严格不超过 PI 上限”的自动推荐。

调教项由当前配件实时生成：胎压无需配件即可填写；可调悬挂解锁车轮定位、弹簧、车高与阻尼；前后竞赛防倾杆分别解锁对应轴参数；竞赛刹车和可调差速器分别解锁对应参数；运动变速箱解锁终传比，竞赛变速箱按实际挡位数解锁逐挡齿比。只有 `adjustable: true` 的前部件解锁前下压力，只有可调尾翼解锁后下压力；宽体和固定尾翼不能自动解锁下压力。空值表示沿用游戏中的原厂设定。
