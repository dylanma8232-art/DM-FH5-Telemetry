## 核心亮点一览

在《极限竞速：地平线 5》里跑陌生自制图、刷山道冲刺赛或自己动手调车时，光靠游戏自带界面既记不住弯道、复盘没有抓手，按下 `T` 键还会把整块挡风玻璃糊满白字。

**`DM-FH5-Telemetry`** 通过监听游戏官方开放的遥测数据流，为你提供一套完整的本地赛车工程遥测平台：

### 1. 跑一圈自动录制赛道、自动生成动态语音路书

无需人工描点——开上赛道跑完一圈，系统自动区分**闭合环道**与**点对点冲刺赛段**，提取全赛道每个弯道的方向、曲率等级与参考车速，生成可微调的拉力路书；实战时按 **实时车速 × 3.5 秒动态提前量** 语音播报（连续复合弯自动合并成句），雨雾夜赛也能提前找准重刹点。

## 五大功能模块

通过顶部导航栏（或键盘快捷键 `1` ~ `5`）在五大工作台之间一键切换：

| 模块（快捷键） | 主要用途 |
|---|---|
| **`1` · 实时仪表盘** | 60 帧/秒实时展示档位车速、换挡提示灯、拉力路书大字领航、四轮胎温胎压、悬挂压缩比、过弯 G 力与分段快慢差 |
| **`2` · 赛道管理** | 自动录制并缝合环道/冲刺赛轨迹，自动划分弯道等级与路书口令；支持手动微调弯心、多段轨迹合并及导出图片/路书文本 |
| **`3` · 比赛中心** | 自动压缩归档每场遥测记录；支持 2D 操控热力图、逐弯入弯/弯心/出弯车速诊断，以及导出 **CSV / 复盘网页 / PDF 报告** |
| **`4` · 车辆管理** | 上车自动识别当前驾驶车型；内置 **700+ 台官方车型基础规格**与单车专属合法候选引擎映射，防止跨车系错配 |
| **`5` · 调教工坊** | 胎压、四轮定位、防倾杆、弹簧阻尼、空力与差速器精细管理，自动识别锁止部件，支持多版本对比与 **AI 遥测问诊** |

## 3 步快速开跑

### 第 1 步：在游戏内开启官方数据输出

进入《地平线 5》 **设置 → HUD 与玩法 → 滚至最底部**：
- **数据输出**：`开启`
- **数据输出 IP 地址**：同一台电脑运行填 `127.0.0.1`；若遥测平台运行在局域网另一台电脑上，填写那台电脑的局域网 IP
- **数据输出端口**：`9996`

### 第 2 步：启动本地遥测平台（默认网页端口 `9188`）

- **macOS 双击一键启动（推荐）**：克隆仓库后直接双击根目录的 [`启动FH5遥测.command`](启动FH5遥测.command)，自动完成依赖检查、前端构建并打印访问地址。
- **Windows / macOS / Linux 命令行启动**（需安装 `Node.js >= 20`）：

```bash
git clone https://github.com/dylanma8232-art/DM-FH5-Telemetry.git
cd DM-FH5-Telemetry/forza-telemetry

npm run install:all
npm run build:client
npm start
```

### 第 3 步：打开网页工作台（或手机副屏）

- **本机或电脑副屏**：浏览器打开 `http://localhost:9188`
- **手机 / 平板副屏（同一 Wi-Fi）**：浏览器打开启动终端里提示的 `http://<电脑局域网IP>:9188`（在手机浏览器点「添加到主屏幕」即可全屏无边框使用）

## 可选进阶配置（AI 调车与语音播报）

基础遥测、自动录赛道、浏览器原生语音报路书与赛后复盘**开箱即用，无需配置任何密钥**。如需开启大模型 AI 调车问诊，可将 [`.env.example`](.env.example) 复制为 `.env`（或在页面右上角设置面板中直接填写）：

| 配置项 | 是否必填 | 说明 |
|---|---|---|
| `DASHSCOPE_API_KEY` | 可选 | 填入阿里云百炼（或任意兼容接口）密钥后，即可在「调教工坊」与「比赛中心」启用 AI 底盘问诊 |
| `DASHSCOPE_BASE_URL` | 可选 | 默认使用百炼兼容地址，也可切换为其他兼容大模型服务商地址 |
| `DASHSCOPE_MODEL` | 可选 | 默认使用 `qwen3.7-plus`，可按需更换推理模型 |
| 语音播报引擎 | 免配即用 | 默认启用浏览器本地低延迟语音播报，支持在设置面板调节语速、提前系数或接入云端语音 |
